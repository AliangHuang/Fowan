# Windows 工具中心与痒痒猫管理

工具中心只收录可用工具，六个规划占位项继续排除。首个工具为
[痒痒猫](https://github.com/AliangHuang/yym)，初始核验版本为
[v0.10.0](https://github.com/AliangHuang/yym/releases/tag/v0.10.0)。设计依据为
[DP-0006](design-proposals/DP-0006-managed-yym-tool.md) 和
[ADR-0012](adr/0012-managed-tool-installations.md)。

## 用户操作

- 启动工具中心只读取本地安装状态，不自动下载、更新或运行痒痒猫。
- 选择痒痒猫后可手动下载并安装；展示待安装版本、已安装版本、程序与用户数据位置。
- 未安装时将目标目录标为“计划安装到”，并说明安装时才创建或使用；不将预设路径当作已有安装。
  没有用户数据时隐藏数据位置；未安装但已有数据目录时明确标注“检测到已有数据目录（未安装）”。
  已安装但数据目录尚未创建时标为“用户数据将保存到”。未安装状态仅对确有的残留提供“清理残留”，
  不显示启动、打开不存在目录或卸载等安装后动作。
- 检查更新只查询公开发布元信息及校验文件；匿名 API 限流时查询公开 latest Release 重定向，
  使用校验文件和包的 HEAD 信息确认版本及大小，无需 GitHub Token。
- 安装前可以选择安装父目录。已安装或存在程序残留时，先卸载，再选择新位置重新安装；
  配置、账号备注和日志默认保留。程序启动、打开目录、项目主页和发布说明均为手动动作。
- 已安装相同版本可重新安装或修复；较新的已安装版本不会被初始内置元数据降级。
- 下载支持进度和取消；校验、解压或写入失败时保留上一份安装记录和完整程序。
- 清理下载缓存及旧版本只处理 Fowan 管理的下载、暂存与非当前版本目录。
- 更新、清理和卸载前需退出受管理的痒痒猫；完整用户数据清理还要求退出其他痒痒猫实例。
- 卸载需确认，默认保留用户数据；另一个复选框明确授权清理当前用户的痒痒猫数据目录。

## 文件位置与边界

默认程序容器为 `%LOCALAPPDATA%\Fowan\ToolCenter\Tools\yym`，选择其他父目录后使用其下的
`FowanTools\yym` 专属容器。容器包含所有权标记、暂存、GUID 版本目录与原子替换的安装记录。
安装位置配置、跨进程操作锁和下载缓存位于 `%LOCALAPPDATA%\Fowan\ToolCenter`。

痒痒猫用户数据固定为 `%LOCALAPPDATA%\yym`。更新和普通卸载保留该目录；完整卸载仅清理该目录，
不根据配置中的来源路径追踪或清理 MuMu 数据盘、缓存来源及其他位置的导出文件。

仅接受官方稳定版的 `yym-<version>-win-x64.zip` 和对应 SHA-256 校验文件，排除源码包。
完整保留 `yym.exe`、`_internal`、README、MIT 及第三方许可证；不运行安装脚本或请求管理员权限。
拒绝越界 ZIP 路径、特殊 Windows 文件名、备用数据流、符号链接和目录联接。
安装与卸载还验证操作开始时的安装位置与界面展示位置一致，防止另一实例改位置后扩大操作范围。

## 验证

单元测试覆盖包选择、匿名限流回退、重定向、校验、取消、并发、路径与归属、异常包、安装修复、
运行中保护、普通/完整卸载及旧版本清理。实际发布包验收使用临时目录与合成数据，默认不启动痒痒猫。
可用 `FOWAN_TOOL_CENTER_PACKAGE_FIXTURE` 指定官方 ZIP，并用 `FOWAN_TOOL_CENTER_LIVE_RELEASE=1`
运行 `GitHubPackageCanBeDownloadedInstalledAndRemovedWithoutLaunching` 验证实际 GitHub 下载与安装链路。
