# Fowan Windows 提醒 UI 设计

## 信息架构

```text
Fowan 提醒
  提醒中心（默认首页）
  番茄钟
  专注记录
  设置
```

主窗口使用 Windows 11 Fluent 桌面样式、浅色/深色/跟随系统主题、可键盘访问的侧栏和
明确的图标可访问名称。最小尺寸为 1000 x 680。

应用品牌与工具箱卡片使用提醒图标。番茄图形保留在番茄钟计时卡片中，表示应用内的
专注功能。Todo 的关联提醒入口显示“在提醒中编辑”，打开后进入提醒中心。

## 番茄钟页

中心为阶段名称、圆形进度与大号倒计时；下方是开始、暂停/继续、停止与跳过。右侧卡片
显示关联 Todo、选择/清除任务入口、当前轮次和下一提醒。阶段结束后展示完成待办按钮，
而不是自动完成。

## 提醒页

顶部有“新建提醒”，下方按即将发生、暂停和失效分组。表单可选相对或绝对时间、循环
规则和 Todo 关联；独立提醒保存后遵循关联询问流程。每日开始/截止摘要设置位于本页
底部的紧凑卡片。

创建、稍后提醒或开关提醒后立即刷新列表与摘要，刷新时保留编辑器内容；在提醒中心与
番茄钟之间切换时保留页面控件及任务选择，避免重复挂载同一个计时控件。

## 记录与设置

专注记录页显示今日/本周汇总和可访问的专注列表。设置页先展示提醒与每日摘要，再以
独立的“番茄钟”分组展示阶段时长、每轮专注数及阶段自动开始开关，保留通知状态、
每日摘要时间和“恢复独立提醒关联询问”。
