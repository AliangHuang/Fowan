# Fowan Windows 番茄钟 UI 设计

## 信息架构

```text
Fowan 番茄钟
  专注
  提醒
  记录
  设置
```

主窗口使用 Windows 11 Fluent 桌面样式、浅色/深色/跟随系统主题、可键盘访问的侧栏和
明确的图标可访问名称。最小尺寸为 1000 x 680。

## 专注页

中心为阶段名称、圆形进度与大号倒计时；下方是开始、暂停/继续、停止与跳过。右侧卡片
显示关联 Todo、选择/清除任务入口、当前轮次和下一提醒。阶段结束后展示完成待办按钮，
而不是自动完成。

## 提醒页

顶部有“新建提醒”，下方按即将发生、暂停和失效分组。表单可选相对或绝对时间、循环
规则和 Todo 关联；独立提醒保存后遵循关联询问流程。每日开始/截止摘要设置位于本页
底部的紧凑卡片。

## 记录与设置

记录页显示今日/本周汇总和可访问的专注列表。设置页包含阶段时长、每轮专注数、阶段
自动开始开关、通知状态、每日摘要时间和“恢复独立提醒关联询问”。
