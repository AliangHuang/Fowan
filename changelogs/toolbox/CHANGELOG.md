# Fowan 工具箱 Changelog

## 0.2.4 - 2026-11-05

- 新增独立工具中心，支持浏览、搜索可用工具，并收录首个工具痒痒猫，提供手动下载安装、启动、更新检查和卸载清理。
- 移除笔记、知识库、文件、全局搜索、工作流和插件六个规划占位入口；工具中心仅收录可用工具。
- 升级安装时将当前安装目录中的工具中心纳入进程关闭范围，避免工具中心占用程序文件；其他安装目录、开发版和独立痒痒猫进程不在此范围内。
- 将番茄钟入口调整为“提醒”，优先打开提醒中心，保留番茄钟和专注记录。
- Windows 安装包改为完整自包含分发，工具箱及随包工具自带 .NET 8.0.29 和所需 Windows App SDK 文件；Windows 10 不再因系统级 .NET 或 Windows App Runtime 检测异常而反复提示安装。
- 安装器仅在缺少 Microsoft Visual C++ Redistributable x64 时从随包载荷自动静默安装；目标机无需联网，运行库要求重启时不会立即启动 Fowan。
- 修复待办切换到便签小窗时可能崩溃、主窗口隐藏后无法继续使用的问题。

## 0.2.3 - 2026-07-29

- 新增番茄钟入口和提醒唤醒协调；工具箱保持驻留时可在提醒到期后启动无界面的分发流程。
- 修复选择“关闭时最小化到托盘”后，正常启动的主窗口可能直接退出的问题。
- 安装包不再携带系统运行库；缺少 .NET、Windows App Runtime 或 VC++ 运行库时会列出缺失项并打开微软下载页。

## 0.2.2 - 2026-07-24

- Windows 正式发布统一为安装包交付，不再提供免安装压缩包；工具箱仍通过校验后的安装包完成更新。

## 0.2.1 - 2026-07-23

- Windows 发布包改为共享 .NET 8 Desktop Runtime 与 Windows App Runtime，减少工具箱和随包工具重复携带的运行时文件；安装器会自动完成依赖安装。

## 0.2.0 - 2026-07-23

- 新增独立汇报工具入口，并将其与 AI Chat、AI 配置中心一同纳入 Windows 发布包和发布说明。

## 0.1.4 - 2026-07-13

- 新增开机自启动安装选项和工具箱设置开关，自启动时无感驻留系统托盘。
- 修复升级安装时旧版 Fowan 进程无法退出导致的文件占用。
- 修复安装器更新日志中文乱码。
- 安装或更新完成后默认启动 Fowan 工具箱。

## 0.1.3 - 2026-07-12

- 更新随工具箱发布的 Todo 任务管理器，包含回收站、筛选、任务详情和清单配色功能。
- 加强 Todo 本地数据写入的并发保护与损坏文件恢复能力。

## 0.1.2 - 2026-07-10

- 将独立的 Fowan 日记工具纳入正式发布包，包含本地日记库、日记本、时间线、标签管理及隐私控制。
- 工具箱入口更新为启动完整日记工具，而非仅展示视觉壳。
- 发布包同时包含更新后的 Todo 主窗口与便签模式运行时。

## 0.1.1 - 2026-07-07

- 新增日记工具入口，用于启动独立 Windows 日记视觉壳。
- 新增启动时自动检查 GitHub Release 稳定版更新。
- 新增更新提示弹窗，支持立即更新、忽略当前版本、稍后提醒和禁用自动检查。
- 新增发布用 `fowan-update.json` manifest，用于校验并下载安装包。

## 0.1.0 - 2026-07-06

- 新增 Windows 工具箱壳层，包含工具搜索、分类、详情面板、设置、诊断、用户资料基础能力和托盘行为。
- 新增组件版本元数据，让打包版本可以一致展示工具箱版本。
- 新增安装器更新日志支持，用于升级安装时提示本次版本变化。
