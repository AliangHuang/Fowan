# Fowan Tool Center Changelog

## 0.2.4 - 2026-11-05

- 新增独立工具中心，支持分类浏览、搜索和工具详情，继承工具箱的语言与主题设置，仅收录可用工具。
- 首个工具为痒痒猫，支持手动下载安装、选择安装位置、启动、检查更新、更新、重新安装和修复；下载包校验 SHA-256 并保留完整运行依赖和许可证。
- 支持打开程序及用户数据目录、清理下载缓存和旧版本、卸载及残留清理；默认保留用户数据，只有显式勾选才清理痒痒猫用户数据，运行期间禁止重装和卸载。
- 未安装时显示“计划安装到”；已存在的用户数据独立标为“检测到已有数据目录（未安装）”，未安装且无数据时隐藏数据路径。
- 痒痒猫由用户按需下载，不随 Fowan 安装包预装，也不会自动下载安装或启动。
