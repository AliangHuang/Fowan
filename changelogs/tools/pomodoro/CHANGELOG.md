# Pomodoro changelog

## 0.2.4 - 2026-11-05

- 应用调整为“Fowan 提醒”，默认打开提醒中心；导航优先提供提醒和每日摘要，保留番茄钟与专注记录。
- 提醒列表和每日摘要随数据变化刷新，刷新时保留正在编辑的提醒表单。
- 番茄钟安装目录自带所需 .NET 运行文件，不再依赖目标机的系统级 .NET 检测；专注计时、Todo 关联和本地提醒行为保持不变。

## 0.2.3 - 2026-07-29

- 新增独立番茄钟，支持专注、短休息、长休息、暂停、恢复、跳过、关联 Todo 任务以及本地会话记录。
- 新增本地独立提醒、Todo 关联提醒、周/月重复规则、稍后提醒和每日开始/截止任务摘要。
- 提醒到期由常驻工具箱安全唤醒番茄钟分发，本地通知不会直接完成 Todo 任务。
